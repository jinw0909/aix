# AI x SOFTWAVE HTML 퍼블리싱

`index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드가 필요 없으며 이미지도 로컬에 포함되어 있습니다.

- 1024px 이상: 웹 레이아웃 / 1023px 이하: 모바일 레이아웃
- 모바일: 상단 햄버거 버튼으로 전체 화면 메뉴 열기, 닫기, Escape 키 지원
- 메뉴 클릭: About → 메인 스테이지, Speaker → 키노트, Tickets → 행사 일정, FAQ → 행사 안내
- 스크롤 시 고정 헤더 높이 반영 및 모션 감소 설정 지원
- 원본 PDF의 이미지를 추출해 사용하고 본문과 시간표는 편집 가능한 HTML로 구현
- 모바일에서는 코인 이미지가 소개 문구보다 먼저 배치됨

## 등록 및 지도

사전 등록 버튼은 같은 창에서 https://k-softwave.com 으로 이동합니다.

페이지 로드 시 기존 지도 영역에 서울 강남구 영동대로 513 코엑스의 Google 지도를 바로 불러옵니다. 지도보기 버튼은 외부 페이지로 이동하지 않고 지도 영역으로 스크롤하고 초점을 이동합니다. 지도 로딩에는 인터넷 연결이 필요합니다.

원본에는 FAQ 메뉴만 있고 본문이 없어 제공된 행사 일정·장소를 기준으로 접고 펼치는 FAQ를 추가했습니다. 행사 사실을 별도로 검증하거나 추가하지 않았습니다.

원본 폰트 파일이 제공되지 않아 시스템 한글 글꼴과 Arial을 사용했습니다. 타이틀 글자 형태는 원본과 차이가 있을 수 있습니다.
